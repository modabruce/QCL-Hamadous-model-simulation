# QCL-Hamadous-model-simulation
Raw Matlab code for Master Graduation Thesis https://kth.diva-portal.org/smash/record.jsf?pid=diva2%3A1956088&dswid=-1325
This project aim to simulation QCL(quantum cascade laser) dynamic model based on Hamadous model(https://doi.org/10.1063/1.3124379), then make comparation with conventional semiconductor lasers(SL) dynamic model.
